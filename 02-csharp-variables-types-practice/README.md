# Practicing C#: Variables and Types

> Part of the [Alura .NET Backend Career](https://www.alura.com.br/carreiras/desenvolvimento-backend-net) path.

## About

A collection of practical exercises focused on variables, data types, type conversion, and arithmetic operations in C#. Each file contains the exercise description as a comment, followed by the solution.

---

## Exercises

| File | Description |
|------|-------------|
| `CalculatingAge.cs` | Calculates a person's age based on their birth year and the current year |
| `CalculatingAreaAndPerimeter.cs` | Calculates the area and perimeter of a circle given its radius |
| `CalculatingTheAreaOfARectangle.cs` | Calculates the area of a rectangular plot of land given width and length |
| `ConvertingHoursToMinutes.cs` | Converts a total number of minutes into hours and remaining minutes |
| `ConvertingTypes.cs` | Converts a decimal weight to an integer to determine the number of required vehicles |
| `DistanceConversion.cs` | Converts a distance in miles to kilometers |
| `DonationRecords.cs` | Stores and displays donation data using different primitive types |
| `GradeAverage.cs` | Calculates the arithmetic average of three student grades |
| `LifeControlInAGame.cs` | Simulates a game life counter using increment and decrement operators |
| `SalaryIncrease.cs` | Calculates a new salary based on a percentage increase |

## Concepts Covered

- **Primitive types** — `int`, `double`, `float`, `decimal`, `bool`, `char`
- **Type conversion** — explicit casting with `(int)` to discard decimal parts
- **Arithmetic operators** — `+`, `-`, `*`, `/`, `%` for division remainder
- **Increment and decrement operators** — `++` and `--` for counter manipulation
- **String interpolation** — building formatted output with `$"...{variable}..."`
- **String formatting** — using `:F2` and `:f1` format specifiers for decimal precision
- **Built-in types and APIs** — `DateTime.Now.Year` to retrieve the current year
- **Variable declaration and assignment** — strongly typed variable declarations across multiple numeric types
