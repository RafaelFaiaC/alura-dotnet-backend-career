# Practicing C#: Conditionals with if/else and switch/case

> Part of the [Alura .NET Backend Career](https://www.alura.com.br/carreiras/desenvolvimento-backend-net) path.

## About

A collection of practical exercises focused on conditional structures in C#. Each file contains the exercise description as a comment, followed by the solution.

## Concepts Covered

- **if/else** — evaluating conditions and branching logic based on multiple criteria
- **else if chains** — handling multiple exclusive conditions in sequence
- **Logical operators** — combining conditions with `&&` (AND) for multi-criteria validation
- **switch/case** — replacing if/else chains for cleaner, more readable branching
- **switch expression** — modern C# syntax for concise value assignment based on a pattern
- **User input parsing** — converting console input with `int.Parse()`, `double.Parse()`, and `decimal.Parse()`
- **String methods** — using `.ToUpper()` for case-insensitive input handling
- **Integer division** — using `/` to extract the leading digit of a number for range-based classification
